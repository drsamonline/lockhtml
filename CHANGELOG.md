## [1.0.0] - 2026-10-20

### Added
- Initial release.
- `lockhtml lock` — encrypt one or many HTML files behind a PIN (AES-256-GCM).
- `lockhtml unlock` — recover the original document with the PIN.
- `lockhtml gui` — open the standalone browser GUI.
- One-time-view mode (best-effort, browser-enforced expiry).
- Cross-platform CLI for Windows, Linux and macOS.
- Self-contained, single-file HTML GUI that runs in any modern browser.
- GitHub Actions CI (tests on Linux, Windows and macOS, Python 3.9–3.12).
- GitHub Pages deployment of the live GUI.
